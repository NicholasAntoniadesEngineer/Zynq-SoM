# som_j1 - module connector J1 (power / USB / STM32 / JTAG / SDIO / ETH MDI)

The board side of module connector J1. The sheet holds the one connector part and is generated from the module interface (`som/som_interface.json`) and this board's `som_mapping.json`; there is no hand-typed pinout. Pins this board gives no function keep the module's net name and end at the pad.
