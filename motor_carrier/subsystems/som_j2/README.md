# som_j2 - module connector J2 (FPGA bank 13/33 IO + VCCO rails)

The board side of module connector J2. The sheet holds the one connector part and is generated from the module interface (`som/som_interface.json`) and this board's `som_mapping.json`; there is no hand-typed pinout. Pins this board gives no function keep the module's net name and end at the pad.
