# Placement rule book

Generated by `schgen rules` from `native/src/rules`. Do not edit by hand; a contract test compares this file with the generated text.

Each rule is one file, `native/src/rules/<area>/<id with underscores>.cpp`, holding the rule, its thresholds and its one check. The order is fixed in `native/src/rules/rule_book.cpp`. The final placement gate runs every rule on the placed board: a GATE rule with findings fails the board, a MEASURED rule reports its findings without failing it. "Met by" names the stage that must satisfy the rule: the starting placement, or the layout stage that seats, arranges and squeezes it.
