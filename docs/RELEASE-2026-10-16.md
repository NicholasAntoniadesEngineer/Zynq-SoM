### Reproduce this publication

Build using [the native build instructions](../native/ci/README.md), then run:

```sh
native/bin/schgen board --project carrier --compact-placement \
  --interior-order 3 --failed-first-retry --edge-feasibility \
  --owned-quality-first --owned-face-cohesion \
  --contract-group-face-sheet usb_jtag --contract-group-face-sheet power \
  --contract-group-face-sheet power_som --contract-group-face-sheet power_mon \
  --floorplan-spec native/benchmarks/carrier-162x151-granular-vertical.floorplan.json \
  --require-bottom-sheet power_mon --require-bottom-sheet bringup_modules \
  --require-bottom-sheet bringup_en_modules \
  --joint-separation-states 1024 --reseat-poses 8 --reseat-frontier 4096 \
  --reseat-continuations 3 --reseat-victim-shapes \
  --owned-shape board_aux=owned-face-a1.000000 \
  --granular-minor-occupancy --vertical-compaction --audit-projections 2 --timing

native/bin/schgen board --project devkit_mini --multiscale-outline \
  --audit-projections 2 --timing
```
