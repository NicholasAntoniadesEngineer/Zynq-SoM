Portable-C bring-up firmware for the SoM STM32 system controller

## Toolchain-agnostic by construction

No file here `#include`s a Zephyr (or any platform) header.  The
portable code calls the `sc_hal` op table (`sc_hal.h`); a platform
port implements that table.  A Zephyr reference port ships as
`sc_hal_zephyr.c.txt` (a `.txt` so the tree stays platform-free) plus
the devicetree-overlay / Kconfig notes in `sc_hal.h`.

## C2 -- watchdog not during power-up

The TPS3823 is an external supervisor; the SC only strobes its WDI.
Per project constraint C2, `sc_wdt_kick()` is a no-op until
`sc_wdt_arm()` is called, and `sc_seq_run()` never arms it -- so a
slow rail ramp cannot trip a reset mid-bring-up.  `sc_app.c` shows the
correct order: sequence rails + modules, **then** `sc_wdt_arm()`.
