# GEOMETRY PIPELINE

GENERATED by `schgen board` from the live stage manifest (`native/src/board_policy_metadata.cpp`), the quantization registry (`native/src/native_audit_registry.cpp`) and the fallback registry (`native/src/native_audit_registry.cpp`). Do not edit by hand — edit the registries and rebuild.

## Placement stages (`build_model`, declared order)

Movement in a `may_move: no` stage raises `StageMovementError` at build time (always-on tripwire; one snapshot hash per boundary). `tracked: no` stages run before absolute positions exist.

| # | stage | may_move | tracked | validated by |
|---|-------|----------|---------|--------------|
| 1 | `zone_pack` — Construct local two-sided zone geometry | yes | no (board) | Native template feasibility, per-zone fanout reservation and shape registration; infeasible contracts fail |
| 2 | `plan_lattice` — Search the outline and place subsystem blocks | yes | no (board) | Occupancy separation, pair recheck, composition legalizer and LAW-5 estimate |
| 3 | `shape_bind` — Apply the plan's registered shape choices | NO | no (board) | Chosen shape index must exist; mirror documents and side membership rebind without moving poses |
| 4 | `step3_emission` — Seed board-frame MH, SoM, zone and decoupling poses | yes | yes (board) | Exact plan origin plus zone offsets; emitted geometry is independently verified later |
| 5 | `l4_pull` — Rigid SoM-ward pull of bottom passive clusters | yes | yes (board) | Bottom/THT/corridor collision set, foreign D13 floors, board margin and dispersion cap |
| 6 | `edge_seat` — Seat off-board connectors at the board edge | yes | yes (board) | Connector pad-flush axis only; final mechanical gate judges the emitted result |
| 7 | `breathe` — Spread starved movable IC groups into free space | yes | yes (board) | Every snapped commit rechecks collision and leash; dispersion failure reverts the sheet, or the complete pass in compact mode to preserve cross-face reservations |
| 8 | `refit_facing` — Turn a downstream contracted zone only when facing requires it | yes | yes (board) | Final placement-flow, contract and DRC gates independently check the rigid turn |
| 9 | `reorder` — Uncross interchangeable parts without changing occupied geometry | yes | yes (board) | Identical footprint/rotation/side slot permutation; strict crossing-count improvement |
| 10 | `corridor_eviction` — Evict bottom strays from the final DF40 stitch corridors | yes | yes (board) | Post-gridified corridor collision, bottom/THT/edge and foreign D13 checks; counted failures |
| 11 | `instantiate` — Project frozen poses into footprint instances | NO | yes (board) | Always-on checkpoint rejects movement of any existing board-frame part |
| 12 | `emission_frame` — Establish the emitted page-frame snapshot including fiducials | yes | yes (page) | Origin translation plus registered fixed-part grid; same grid used for corridor prediction |
| 13 | `escape_copper` — Derive return stitching and lane copper from frozen footprints | NO | yes (page) | Always-on checkpoint forbids footprint movement; final return-stitch/escape gates |

## Fallback registry + committed ratchet baselines

Every alternate path is a NAMED event. The board gate (`check_board_fallbacks` in `native/src/verification_audits_counts.cpp`) separates explicitly reviewed search effort from non-search regressions. Search counts have no acceptance ceiling: the committed values below are historical references, not hardware limits. Non-search and unreviewed paths retain the ratchet. Live counts, including failed trials and budget exhaustion, remain in the build report and `board_verdicts.json` (`fallbacks`). Independent electrical and physical checks decide board correctness; search exhaustion does not prove infeasibility.
